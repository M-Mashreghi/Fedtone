# Documentation Rules

All repository documentation should be written in English.

When implementation changes behavior, update the relevant documentation in the same task.

Common files:

- `docs/ARCHITECTURE.md` — architecture and invariants
- `docs/ROADMAP.md` — product horizons and KPIs
- `docs/PHASES.md` — phase scope and Definition of Done
- `docs/PROJECT_PHASES_AND_TASKS.md` — atomic task source of truth
- `docs/TASKS.md` — progress ledger and verification evidence
- `docs/DIAGRAMS.md` — Mermaid architecture/workflow diagrams
- `docs/DEPLOYMENT.md` — deployment/CI/CD
- `docs/RUNBOOK.md` — operational incidents and maintenance

Do not mark documentation tasks complete before corresponding implementation/test evidence exists.
