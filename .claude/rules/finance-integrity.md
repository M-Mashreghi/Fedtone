# Financial Research Integrity

## No Look-Ahead Bias

All historical analysis must respect point-in-time information.

Never use future information when constructing a historical signal, including:

- future central-bank statements
- future prices
- future consensus estimates
- later revisions that were unavailable at the event timestamp
- future macro releases

Any dataset with revisions must document whether values are real-time/vintage or revised.

## Deterministic Calculations

Financial calculations must be implemented in Python, not generated by an LLM.

This includes:

- simple/log returns
- volatility
- yield changes
- basis-point moves
- abnormal returns
- cumulative abnormal returns
- event-window aggregations
- significance statistics

LLMs may interpret calculated values but must not fabricate them.

## Event Windows

Event studies must explicitly define:

- event timestamp
- event timezone
- market timezone
- estimation window
- event window
- benchmark/model where applicable

Common windows may include `[0,+1]`, `[0,+5]`, `[0,+20]`, but each analysis must state its actual definition.

## Reproducibility

A research result should be reproducible from:

- source document/version
- source and publication timestamps
- market dataset/version
- model identifier
- prompt version
- analysis configuration
- code commit where practical
